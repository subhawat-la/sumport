# FinancialLog

Web application สำหรับบันทึกยอดสินทรัพย์ส่วนตัวทุกประเภทในที่เดียว เพื่อดูภาพรวมพอร์ตเกษียณและจัดทำงบดุลส่วนบุคคล
(SSF, RMF, Thai ESG, กองทุนรวม, PVD, หุ้นไทย, หุ้นต่างประเทศ, คริปโต, ทองคำ, หุ้นกู้, เงินฝาก และสินทรัพย์อื่นๆ)

- เก็บเฉพาะ **ยอดปัจจุบัน** ของแต่ละสินทรัพย์ (จำนวนที่ถือครอง × ราคา/NAV) ไม่ต้องบันทึกรายการซื้อขาย
- Export เป็น **Excel (.xlsx)** สำหรับทำงบแสดงฐานะการเงินส่วนบุคคล
- ใช้งานคนเดียว **ไม่มี server และไม่มีฐานข้อมูล** — ข้อมูลเก็บในเบราว์เซอร์ของเครื่องที่ใช้
- ย้ายไปใช้อุปกรณ์อื่นได้ด้วยไฟล์สำรองที่เข้ารหัส (`.flbak`)
- ล็อกแอปด้วย PIN และเข้ารหัสข้อมูลในเครื่อง (AES-256-GCM)

## วิธีเปิดใช้งาน

ดับเบิลคลิก `index.html` เพื่อเปิดใน Edge หรือ Chrome — ไม่ต้องติดตั้งหรือ build
ครั้งแรกจะมีให้เลือก: เริ่มใช้งานจริง / กู้คืนจากไฟล์สำรอง / ทดลองด้วยข้อมูลตัวอย่าง

> ข้อมูลผูกกับ **เบราว์เซอร์และ profile** ที่ใช้เปิด หากเปลี่ยนเบราว์เซอร์หรือเครื่อง ให้ใช้ไฟล์สำรองเพื่อย้ายข้อมูล
> การสั่งล้างข้อมูลการท่องเว็บ (cookies และข้อมูลไซต์) จะลบข้อมูลของแอปด้วย จึงควรสำรองข้อมูลสม่ำเสมอ

## หน้าจอ

| หน้า | URL | หน้าที่ |
|------|-----|---------|
| ภาพรวม | `#/dashboard` | มูลค่ารวม, กำไร/ขาดทุน (เฉพาะรายการที่ระบุต้นทุน), สัดส่วนสินทรัพย์, มูลค่าย้อนหลัง (บันทึกอัตโนมัติรายวัน), สรุปตามหมวดงบดุล, Top 5, ราคาที่ควรอัปเดต |
| สินทรัพย์ | `#/holdings` | กรอง/ค้นหา/เรียง/จัดกลุ่ม, ปุ่ม ✏️ แก้จำนวน/ราคารายตัว, Export Excel |
| รายละเอียด | `#/holding/:id` | จำนวนที่ถือครอง, NAV, มูลค่า, ต้นทุน (ถ้าระบุ), กำไร/ขาดทุน, กราฟราคา |
| เพิ่ม/แก้ไข | `#/add`, `#/edit/:id` | ฟอร์มปรับตามประเภทสินทรัพย์: จำนวนที่ถือครอง, ราคา/NAV, ต้นทุนรวม (ไม่บังคับ), แหล่งราคาอัตโนมัติ |
| อัปเดตยอด/ราคา | `#/prices` | แก้จำนวนที่ถือครองและราคา/NAV หลายรายการพร้อมกัน (ไฮไลต์ช่องที่แก้, แสดงมูลค่าใหม่ทันที, Enter ไปช่องถัดไป) + ดึงราคาอัตโนมัติ |
| ตั้งค่า | `#/settings` | PIN, ล็อกอัตโนมัติ, สำรอง/กู้คืน, API key, ชื่อเจ้าของ, ลบข้อมูล |

## Export Excel

ปุ่ม **📊 Export Excel** (เมนูด้านข้าง, หน้าภาพรวม, หน้าสินทรัพย์) สร้างไฟล์ `FinancialLog-Assets-YYYY-MM-DD.xlsx` ในเบราว์เซอร์ (ไม่ต้องต่ออินเทอร์เน็ต) ประกอบด้วย 2 ชีต:

1. **งบดุลส่วนบุคคล** — สินทรัพย์แยกตามหมวดงบดุล (สภาพคล่อง / เพื่อการลงทุน / กองทุนเพื่อการเกษียณและระยะยาว / ส่วนตัวและอื่นๆ) และประเภทสินทรัพย์ พร้อมสัดส่วน, ส่วนหนี้สิน (ช่องสีเหลืองให้กรอกเอง) และ **ความมั่งคั่งสุทธิ** คำนวณด้วยสูตร
2. **รายการสินทรัพย์** — ทุกรายการ: หมวด, ประเภท, ชื่อ, รหัส, แพลตฟอร์ม, จำนวนที่ถือครอง, ราคา/NAV, ราคา ณ วันที่, สกุลเงิน, อัตราแลกเปลี่ยน, มูลค่า (บาท), สัดส่วน, ต้นทุน, กำไร/ขาดทุน, หมายเหตุ (มี filter และตรึงแถวหัวตาราง)

ตัวเลขในชีตงบดุลเชื่อมกับชีตรายการด้วยสูตร (`SUMIFS`) หากแก้ไขตัวเลขในชีตรายการ งบดุลจะคำนวณใหม่ให้อัตโนมัติ

## การอัปเดตราคา

แอปทำงานในเบราว์เซอร์ล้วน จึงเรียกได้เฉพาะแหล่งข้อมูลที่อนุญาต CORS โดยอัปเดตอัตโนมัติวันละครั้งเมื่อเปิดแอป

| ข้อมูล | แหล่ง | วิธี |
|--------|------|------|
| USD/THB | ECB ผ่าน [Frankfurter](https://frankfurter.dev) | อัตโนมัติ ไม่ต้องใช้ key |
| คริปโต | [CoinGecko](https://www.coingecko.com) | อัตโนมัติ ไม่ต้องใช้ key (map จากสัญลักษณ์ หรือระบุ CoinGecko ID เอง) |
| หุ้น/ETF สหรัฐ | [Twelve Data](https://twelvedata.com) | อัตโนมัติ ต้องใส่ API key ฟรีที่หน้าตั้งค่า (จำกัด 8 สัญลักษณ์/นาที) |
| กองทุนไทย, หุ้นไทย, ทอง, PVD, หุ้นกู้, เงินฝาก | — | กรอกเองที่หน้าอัปเดตยอด/ราคา (มีลิงก์ไปดูราคาล่าสุด) |

แหล่งข้อมูลไทย (ก.ล.ต., ธปท., SET/Settrade, สมาคมค้าทองคำ, Finnomena) ไม่รองรับ CORS
หากต้องการดึงอัตโนมัติในอนาคต ต้องเพิ่ม relay ขนาดเล็ก เช่น Cloudflare Worker (ตัดสินใจไม่ทำในเฟสนี้)
ข้อมูลที่ส่งไปยังผู้ให้บริการมีเพียงสัญลักษณ์สินทรัพย์ ไม่มีจำนวนหน่วยหรือมูลค่าพอร์ต

## ความปลอดภัยและการจัดเก็บ

- เก็บใน `localStorage` (key `financiallog.vault`) และขอให้เบราว์เซอร์จัดเก็บแบบถาวร (`navigator.storage.persist`)
- เมื่อตั้ง PIN 6 หลัก ข้อมูลทั้งก้อนถูกเข้ารหัสด้วย AES-256-GCM โดยกุญแจได้จาก PBKDF2-SHA256 (600,000 รอบ)
- ใส่ PIN ผิดตั้งแต่ครั้งที่ 5 จะถูกหน่วงเวลาเพิ่มขึ้นเรื่อยๆ (สูงสุด 15 นาที) และล็อกอัตโนมัติเมื่อไม่ได้ใช้งาน (ค่าเริ่มต้น 5 นาที)
- **ลืม PIN = กู้คืนได้จากไฟล์สำรองเท่านั้น**
- ข้อจำกัด: PIN 6 หลักป้องกันการเปิดดูจากผู้ที่ใช้เครื่องร่วมกัน แต่ไม่ทนต่อการเดาแบบ offline หากผู้โจมตีได้สำเนาข้อมูลจากเครื่องไปแล้ว ไฟล์สำรองจึงใช้รหัสผ่านแยกที่ยาวกว่า (≥ 8 ตัวอักษร)

## ไฟล์สำรองและการย้ายอุปกรณ์

1. ตั้งค่า → ดาวน์โหลดไฟล์สำรอง → ตั้งรหัสผ่านไฟล์
2. ส่งไฟล์ `.flbak` ไปเครื่องใหม่ (OneDrive, Google Drive, AirDrop ฯลฯ)
3. เปิด FinancialLog บนเครื่องใหม่ → กู้คืนจากไฟล์สำรอง → ใส่รหัสผ่าน → ตั้ง PIN

รูปแบบไฟล์ (มาตรฐานเปิด เพื่อให้อ่านได้ในระยะยาวแม้ไม่มีแอป):

```json
{
  "app": "FinancialLog", "kind": "backup", "format": 1, "schemaVersion": 2, "createdAt": "...",
  "encrypted": true,
  "kdf": { "name": "PBKDF2", "hash": "SHA-256", "iterations": 600000, "salt": "<base64>" },
  "cipher": { "name": "AES-GCM", "iv": "<base64>" },
  "data": "<base64 ciphertext ของ JSON ข้อมูลทั้งหมด>"
}
```

ถอดรหัสโดยไม่ใช้แอป: `pip install cryptography` แล้ว `python tools/decrypt_backup.py <ไฟล์>.flbak -o data.json`

คำแนะนำสำหรับพอร์ตเกษียณ: สำรองอย่างน้อยเดือนละครั้ง (แอปจะเตือนตามรอบที่ตั้งไว้), เก็บไฟล์ 2 ที่ และจดรหัสผ่านไฟล์ไว้ใน password manager

## Data model (schema v2)

แต่ละสินทรัพย์เก็บเฉพาะยอดปัจจุบัน — มูลค่า = `units × price` (เงินฝากใช้ `balance`) และ `cost` เป็นข้อมูลเสริมสำหรับคำนวณกำไร/ขาดทุน

```
Holding   { id, type, name, symbol, platform, currency, units, price, priceDate, balance*, cost?, updatedAt,
            priceHistory[], autoPrice, sourceId, extra{}, note }
Snapshot  { date, value }                    มูลค่ารวมรายวัน (ใช้วาดกราฟย้อนหลัง)
Profile   { displayName }
Settings  { autoLockMinutes, autoUpdatePrices, backupReminderDays, lastBackupAt, lastPriceUpdate, apiKeys{} }
```

`*` balance ใช้กับเงินฝาก · หมวดงบดุลกำหนดตามประเภทสินทรัพย์ (`bs` ใน `js/config.js`)

`priceHistory` และ `snapshots` เก็บรายวันย้อนหลัง ~13 เดือน ส่วนที่เก่ากว่านั้นเก็บเดือนละ 1 จุด เพื่อให้ขนาดข้อมูลเหมาะกับการใช้งานหลายสิบปี
เมื่อโครงสร้างข้อมูลเปลี่ยน ให้เพิ่ม `schemaVersion` และขั้นตอนใน `migrate()` (`js/vault.js`) เพื่อให้เปิดไฟล์สำรองเก่าได้เสมอ
(v1 → v2: แปลงรายการธุรกรรมเดิมเป็นจำนวนที่ถือครองและต้นทุนรวม แล้วเลิกเก็บธุรกรรม)

## ข้อควรทราบ

- มูลค่าสินทรัพย์ USD คิดด้วยอัตราแลกเปลี่ยนปัจจุบัน
- กำไร/ขาดทุนแสดงเฉพาะรายการที่ระบุต้นทุนรวม
- ยังไม่รองรับ: เป้าหมาย/Rebalance, การแจ้งเตือน, หลายพอร์ต
